## 诉求

【电脑】面板里出现失败时，只显示一句「电脑检查失败。请重试；若仍失败，请查看诊断日志。」，用户拿不到可操作的信息。希望**把具体报错日志直接显示在这个面板里**（可折叠），而不是让用户自己去找日志文件。

## 现状（截图描述）

面板内容：

- 标题：本机 Computer
- 状态标签：需要处理
- 说明：直接操作运行 DSH 的这台电脑（macOS、Windows 或 Linux）。首次检查会安装桌面操作组件；没有显示器的 Linux 服务器会启动一个虚拟桌面。登录请在这台电脑上完成。
- 红色错误：「电脑检查失败。请重试；若仍失败，请查看诊断日志。」
- 唯一按钮：检查权限

问题在于：错误只告诉用户「去看诊断日志」，既没有入口、也没有摘要，普通用户不知道日志在哪，也复制不出来。

## 预期

- 失败时在面板内直接展示最近一次检查的关键错误（一两行摘要），并提供「查看完整日志」「复制」按钮；
- 若有错误码或失败阶段（安装组件 / 连接 / 权限 / 虚拟桌面启动），标一下是哪一步；
- 「重试」保留，但重试后仍失败时应把新日志刷新到面板。

## 影响

这个面板是 Computer 功能的唯一入口，失败时用户只能干看着一句提示；实测群里已出现「找不到这个日志在哪里」的追问，说明提示不可操作。

## 建议实现（供参考）

面板里加一个可折叠的「详细信息」区：默认收起，展开后显示最近 N 行日志与失败阶段；再加「打开日志目录」与「复制错误」两个动作。日志来源复用现有诊断包的数据，不必新造一条链路。
