## 现象

安装 bots（Tobs）插件后，DSH 直接卡死；卸载插件后立即恢复正常。

- 报告者原话：「装完直接卡死」「卸载掉 bots 插件就恢复了，不卡了」「真的服了」。
- 属于安装即不可用，用户无法进入产品。

## 环境

- 桌面端（具体系统待补）
- Tobs 版本待补（推测 1.6.0）
- DSH 版本待补

## 复现步骤

1. 在 DSH 中安装 Tobs 插件；
2. 启动 / 打开界面；
3. 界面卡死，无法操作；
4. 卸载插件后恢复。

## 预期

安装插件后应能正常启动与使用。

## 实际

安装即卡死，卸载即恢复。

## 初步判断

- 插件加载阶段（bundle patch 应用、Bot 面板初始化）存在阻塞或死循环；
- 也可能是旧版残留与新版 bundle 混用（用户是否先卸旧再装新尚未确认）；
- 若同一环境下「装插件即卡死」，优先级高于任何 UI 卡顿，因为它拦住了全部新用户。

## 待补信息

- 精确版本（Tobs / DSH）与操作系统；
- 卡死时机：启动即卡、进入 Bot 面板时、还是首次创建 Bot 时；
- 安装前是否清理过旧版本；
- Host 日志（`daemon.log` 或桌面端日志）最后若干行。

## 影响

阻断级：新装用户无法使用，只能卸载回到无 Bot 状态。
