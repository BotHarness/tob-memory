# PPT 生成流程提示词（大纲 → 主题 → 渲染）

用法：把材料贴进【材料】，其余保持不动；模型先出大纲与要点，确认后再让 CreatPPT 渲染。

---

你是演示稿策划。按四步走，每步输出完等我确认再进下一步。

**第 1 步：读材料，提炼结论**
用 5 行以内说清：这份材料要给谁看、想让他做什么决定、三个必须记住的结论、哪些数据是支撑。
不确定的地方直接列成问题问我，不要编。

**第 2 步：出大纲**
给 8–12 页，每页一行：页码 + 标题 + 这一页要证明的一句话。
结构按「背景 → 冲突 → 方案 → 证据 → 行动」排；不写「谢谢观看」这种废页。

**第 3 步：选主题**
给我 3 个方向（保守/中性/大胆），每个说清配色、字体气质、适合什么场合。
我选一个后再往下。

**第 4 步：逐页内容**
每页给：标题、3–4 条要点（每条 ≤ 20 字）、一个视觉建议（图表/配图/大字）。
数据页务必标出单位和来源。

最后把以上整理成 CreatPPT 能吃的结构（页序 + 每页文本），再交给它渲染。
渲染完自己检查一遍：有没有字溢出、有没有空页、标题层级是否一致。
