## Summary

After installing the plugin, the app opens directly in Bot mode. Users cannot find how to return to the standard Harness workspace; the only known entry is a small icon at the top-left, which is easy to miss. Reported by users after install; I did not reproduce it myself and did not capture version or platform.

## Actual behaviour

- First launch after install lands in Bot mode.
- No visible hint explains how to switch back to the standard workspace.
- The top-left Bot icon appears to be the only toggle; users assume the previous Harness interface is gone.

## Expected behaviour

A discoverable way back to the standard workspace, for example a first-run hint or a clearer affordance in the Bot-mode header.

## Impact

New users can believe the install replaced their Harness UI, which causes confusion and support questions.

## Workaround

Click the Bot icon at the top-left to switch back to the standard workspace.

## Environment

Unknown: product version, platform (desktop, mobile or web) and install path were not captured. User-reported, not reproduced.
